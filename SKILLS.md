# Project Skills

This frontend project is configured to support these design and quality skills:

- Impeccable: premium product design and UI refinement for product surfaces.
- Web design guidelines: review UI against Vercel-style web interface checks.
- Design taste frontend: apply a polished, high-quality frontend aesthetic appropriate for a product or SaaS landing/dashboard experience.

## Recommended usage
- Use Impeccable when polishing the dashboard, auth flows, or overall visual system.
- Use Web design guidelines when reviewing layout, spacing, hierarchy, and accessibility quality.
- Use Design taste frontend when expanding the brand look toward a more refined fintech/product design language.

## Current project status
- Frontend styling is already using a Vercel-like token system.
- Playwright smoke tests cover critical auth and dashboard flows.
- Product documentation and Copilot instructions are included to keep the project aligned with those design principles.
