# BTS Product Brief

## Product
BTS is a personal banking application for managing bank accounts, checking balances, transferring funds, and reviewing recent transaction activity. The product is built for clarity, trust, and speed.

## Core user flows
- Sign up and log in
- Create one or more bank accounts
- View account balances
- Send money between accounts
- Review recent transfers and account activity
- Log out securely

## Design direction
- Minimal, premium fintech aesthetic
- High contrast with clean typography and generous spacing
- Strong hierarchy for totals, account cards, and actions
- Light and dark mode support
- Clear state handling for success, error, and loading

## Primary user goals
1. Understand current financial position at a glance.
2. Move money safely and confidently.
3. Access recent activity without confusion.

## Non-functional requirements
- Functional React app with secure auth token handling
- Validations for transfer inputs and account creation
- Responsive layout for desktop and mobile
- Playwright smoke coverage for critical flows
